# Skills icon assets

These 25 SVG technology logos are sourced from the open-source
[Devicon](https://github.com/devicons/devicon) icon collection.

Devicon icons are distributed under the MIT License. See the upstream
repository for its license and individual third-party brand/trademark policies.

Icons are served locally from /assets/skills/; no requests are made to the
reference portfolio or to an icon CDN at runtime.

Some concepts in the text skill lists (for example generic SQL, dbt, and REST APIs)
were not shown as logos because this set does not provide a clean, unambiguous
logo for those concepts.
